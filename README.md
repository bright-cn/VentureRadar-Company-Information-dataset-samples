此 **VentureRadar 公司信息数据集样本**包含 **1,000 条记录**，并通过 **Bright Data API** 提取。

## 数据点

| 字段名称 | 描述 |
|------------|-------------|
| `url` | 公司在 VentureRadar 上的唯一资料页面 URL。 |
| `location` | 公司的地理位置。 |
| `name` | 公司的正式名称。 |
| `country_code` | 代表公司所在地的 ISO 国家/地区代码。 |
| `ownership` | 公司的所有权类型，例如私营公司或上市公司。 |
| `score` | 反映公司整体地位或表现的公司评分。 |
| `auto_analyst_score` | 反映分析师评估结果的自动化评分。 |
| `website_popularity` | 反映公司网站在互联网上受欢迎程度的指标。 |
| `email` | 公司的联系邮箱地址，出于隐私保护已部分隐藏。 |
| `keywords` | 与公司所属行业或领域相关的关键词。 |
| `linkedin` | 公司的 LinkedIn 资料页面 URL。 |
| `twitter` | 公司的 Twitter 用户名。 |
| `founded` | 公司的成立年份。 |
| `title` | 公司的头衔或称谓。 |
| `description` | 对公司业务和产品服务的简要描述。 |
| `description_source` | 公司描述的来源。 |
| `website` | 公司的官方网站 URL。 |
| `website_popularity_graph` | 展示公司网站受欢迎程度趋势的图表数据。 |
| `similar` | 在性质或业务方面与该公司相似的公司列表。 |
| `sub_scores` | 用于评估公司各个方面的详细子评分。 |
| `hostorical_profiles` | 公司的历史资料数据。 |
| `areas_of_focus` | 公司重点开展业务的主要领域或行业。 |
| `cards` | 与公司相关的其他信息卡片。 |
| `funding_signals` | 反映公司融资活动或融资需求的指标。 |
| `employee_satisfaction` | 反映公司员工满意度的指标或评分。 |
| `company_id` | 数据集中分配给该公司的唯一标识符。 |


## 使用场景

### 1. 市场分析
利用此数据集进行深入的市场分析，并识别各个行业的新兴商业趋势。

### 2. 竞争情报
使用此数据集深入了解竞争对手的优势和劣势，为战略性业务决策提供支持。

### 3. 投资机会
通过分析公司评分和重点行业领域，识别有潜力的初创企业和公司，以发掘潜在投资机会。
